# Spielend Entdecken – WordPress Custom Theme

**Ein maßgeschneidertes FSE-Blocktheme für spielend-entdecken.de**

## Überblick

Modernes, schnelles und kindgerechtes WordPress-Theme für einen Spielzeug-Onlineshop.  
Basierend auf **Full Site Editing (FSE)** – kein Page-Builder, keine überflüssigen Plugins.

## Features

- **Full Site Editing (FSE)** – theme.json-gesteuertes Design
- **WooCommerce-optimiert** – schneller Checkout, reduzierte Scripts
- **Performance** – LCP < 1,5s, keine externen Abhängigkeiten
- **Admin-Optionsseite** – Social-Media-Links, Kontakt, Newsletter, Farben
- **Block Patterns** – Hero, Kategorie-Grid, Testimonials, Newsletter
- **SEO** – JSON-LD, Open Graph, Twitter Cards
- **DSGVO-konform** – rechtliche Texte, Impressum, Datenschutz

## Technologie

| Komponente | Technologie |
|-----------|-------------|
| CMS | WordPress 7.0+ |
| Theme | Custom FSE-Blocktheme |
| Shop | WooCommerce (optimiert) |
| Page Builder | Keiner – native Gutenberg-Blöcke |
| Custom Fields | ACF (optional) |
| SEO | Yoast SEO / Rank Math |
| Kontakt | Contact Form 7 |

## Installation

1. Theme als ZIP herunterladen
2. In WordPress unter **Design → Themes → Installieren** hochladen
3. Aktivieren
4. Empfohlene Plugins installieren: WooCommerce, ACF, Contact Form 7, Yoast SEO
